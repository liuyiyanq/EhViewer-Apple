# EH-11 下载失败原因显示与按类型处理

目标：下载失败时在下载页看得到原因；509、IP 封禁这类账号级错误暂停整个队列，不再一本接一本地失败；画廊已删除这类错误不再逐页重试
范围与不做项：涉及 `Packages/EhSpider/Sources/EhSpider/SpiderQueen.swift`（错误分类、整本停止）、`Packages/EhDownload/Sources/EhDownload/DownloadManager.swift`（失败原因、暂停队列）、`ehviewer apple/DownloadsView.swift`（显示）。不做逐页失败详情和"只重试失败页"；不写失败日志；失败原因不存数据库，重启 App 后不保留
事项类型与 TAPD 关键字：无 TAPD，本地编号 EH-11
相关文档：[EH-10 下载节奏对齐安卓](../下载提速对齐安卓/TASK.md)；[EH-3 下载失败率高](../下载失败率高/TASK.md)；[下载限速与配额参考](../下载限速与配额参考.md)；执行顺序见 [本期执行计划](../PLAN.md)

## 行为与契约

| 错误类型 | 包含 | 处理 | 下载页显示 |
| --- | --- | --- | --- |
| 账号级 | 509 配额用完、IP 被临时封禁、请求过快、登录失效或无里站权限（Sad Panda、kokomade、igneous 无效）、Cloudflare 验证拦截 | 立即停止这本，其余等待中的画廊全部改为已暂停，不再开始下一本 | 这本"失败 · 原因"；下载页顶部"下载已暂停：原因"（IP 封禁带剩余时间） |
| 画廊级 | 画廊已删除、画廊不可用、内容警告 | 立即停止这本，不再逐页重试；下一本照常开始 | "失败 · 原因" |
| 其他（网络、节点、解析） | 超时、连不上、图片下载失败、找不到页面链接等 | 按 EH-10 规则重试；整本失败时显示最后一次失败的原因 | "失败 · 原因" |

- 顶部提示在恢复任意画廊、全部开始或新增下载时清除
- 隐私模式下失败项在进度行右侧显示原因（不含标题等内容）
- 509 仍照旧发系统通知

必须保持：EH-10 的重试规则（11-16 起不换节点）；已下载的页不重下；暂停、删除语义不变
