# EH-7 下载页网格视图与拖动插入排序

目标：下载页在列表之外提供网格视图（一行多本，类似「文件」App），方便快速浏览大量下载；网格中拖动格子到另一个格子上松手即可调整顺序，画廊拖到文件夹上即移入分组
范围与不做项：只涉及 `ehviewer apple/DownloadsView.swift`；顺序与分组的落盘沿用 EH-4 的 `DownloadManager.reorder`、`moveGalleries`，不改目录与序号规则。不做拖动过程中其他格子实时让位（方案 B）；不包装 UIKit `UICollectionView`（方案 C）；不做按时间、标题等排序
事项类型与 TAPD 关键字：无 TAPD，本地编号 EH-7
相关文档：[EH-4 下载列表分组与手动排序](../下载列表分组与排序/TASK.md)（序号、整层编号、移入分组的规则）；执行顺序与跨任务约束见 [本期执行计划](../PLAN.md)

## 行为与契约

允许变化：下载页的显示方式与交互；本地封面缩略图尺寸
必须保持：列表视图的行为不变（含编辑模式拖动排序、右滑操作）；目录名、序号与整层编号规则不变（EH-4）；网格与列表显示同一套顺序（`listEntries`）；搜索、状态筛选、批量选择在两种视图下结果一致

| 输入或事件 | 预期结果 | 依据 |
| --- | --- | --- |
| 工具栏「显示方式」按钮选「网格」 | 下载页改为网格，重启后仍是网格；首页列表模式不受影响 | 决策 6；EH-9 起切换按钮从省略号菜单移到工具栏 |
| 网格中点画廊格子 | 打开阅读器 | 决策 5 |
| 网格中长按画廊格子 | 菜单含暂停或继续、画廊详情、分享（已完成）、移动到分组、删除 | 决策 5 |
| 拖动悬停在某格的左半边 / 右半边 | 该格左侧 / 右侧的格子间隙出现竖线；松手后插到它前面 / 后面；目录名按 EH-4 规则更新 | 决策 9 |
| 把第 1 格拖到第 5 格右半边松手 | 被拖的画廊排到原第 5 格之后 | 决策 9 |
| 拖动中经过某个格子 | 该格子显示高亮边框 | 实现要点 3 |
| 把画廊拖到文件夹格子中间（左右各留 1/4）松手 | 文件夹整格描边；松手后画廊移入该分组；落在文件夹两侧则排在它前后 | 决策 4、9 |
| 把文件夹拖到另一个格子上松手 | 只调整文件夹在根目录中的位置（落在目标文件夹中间时按占据目标位置处理） | 决策 4、9 |
| 搜索、状态筛选或批量选择时 | 格子不能拖动 | 与列表一致（`canReorder`） |
| 批量选择时点格子 | 选中或取消选中，格子左上角显示勾选 | 实现要点 2 |

实现要点：

1. 切换入口：用 `@AppStorage` 记住；网格模式下不显示编辑按钮。EH-9 起改为工具栏单独的「显示方式」按钮（列表、网格、隐私），不再放在省略号菜单里
2. 网格单元：`LazyVGrid` 自适应列宽（最小 100pt，iPhone 一般 3 列）；画廊格子为 2:3 封面 + 两行标题 + 一行状态；未完成的画廊在封面右上角显示状态图标，下载中或等待中在封面底部显示进度条。文件夹格子为 2×2 封面拼贴 + 数量角标 + 组名
3. 拖动插入：每个格子 `draggable`（内容为条目 id）+ `dropDestination`；松手后计算新顺序，交给已有的 `moveEntries`，由 `DownloadManager.reorder` 落盘
4. 菜单共用：画廊长按菜单抽成 `DownloadTaskMenu`，文件夹菜单抽成 `groupMenu`，列表与网格共用；状态图标与状态文字同样共用
5. 封面清晰度：本地封面缩略图从 150px 提到 300px，网格格子更大
