# EH-4 下载列表分组与手动排序

目标：下载列表支持一层分组（文件夹）和手动排序；分组与顺序直接体现在 download 目录结构和目录名上；旧版本下载的画廊无需迁移即可显示，手动排序后获得序号；文件夹与画廊混排显示，文件夹显示内部画廊数量和叠放封面
范围与不做项：涉及 DownloadManager 路径解析与移动排序、DownloadsView 列表、SettingsView 的恢复下载项目和清除冗余、SpiderDen 下载目录来源；下掉下载标签功能。不做多层嵌套分组；不把旧标签转换为分组；不删除数据库中的 label 字段和 downloadLabel 表
事项类型与 TAPD 关键字：无 TAPD，本地编号 EH-4

## 行为与契约

允许变化：下载目录内画廊与分组的目录名；下载列表的展示与交互；下载标签相关 UI 与接口
必须保持：画廊目录内的图片文件名和 `.ehviewer` 格式不变；旧格式 `gid-标题` 目录无需改名即可识别；改名和移动不复制文件；正在下载或阅读的画廊不会因改名丢页或写错目录；用户数据库中已有的 label 数据保留不删

目录与命名规则：

```
download/
├── 000100_汉化精选/              分组：序号_组名，目录内没有 .ehviewer
│   ├── 000100_2345678-标题A/     已排序画廊：序号_gid-标题
│   └── 2345680-标题C/            未排序画廊：旧格式
├── 000200_1234567-标题B/
└── 1111111-旧画廊/               旧版本画廊，原样兼容
```

- 目录类型：根目录下含 `.ehviewer` 的子目录是画廊，不含的是分组；分组内只认含 `.ehviewer` 的子目录
- 画廊身份只认 `.ehviewer` 中的 gid，任何地方都不再从目录名解析 gid
- 序号：可选前缀，6 位数字加 `_`；旧格式数字后是 `-`，两者不会混淆
- 分组只有一层；分组目录内出现的子分组忽略
- 组名取目录名去掉序号前缀；新建或重命名分组时，非法字符替换为 `_`

排序规则：

- 同一层（根目录或某个分组内）的文件夹和画廊共用一套序号
- 有序号的按序号升序在前，无序号的在后，按下载时间倒序
- 某一层首次手动排序时整层按 100、200、300 重新编号，旧画廊此时获得序号
- 之后移动一项只改该项：取相邻两项的中间值，没有空位时整层重新编号
- 按时间、标题、页数等排序只改变显示，不改目录名

实现要点（计划）：

1. 防误删：清除冗余（`ehviewer apple/SettingsView.swift:1825`、`:1892`）和恢复下载项目（同文件 `:1746`）改为只认 `.ehviewer`，扫描根目录和一层子目录；恢复时标题去掉序号前缀；`SpiderInfoFile.scanOfflineGalleries` 同步改
2. 路径索引：启用已有但未使用的 `downloadDirname` 表，存 gid → 相对路径；`DownloadManager.galleryDirectory` 改为先查索引，查不到再按旧规则拼；SpiderDen 改用 DownloadManager 解析的目录；进入下载页时扫描两层目录（只读 `.ehviewer` 头部）刷新索引
3. 移动与排序：DownloadManager 增加新建、重命名、解散分组，移动画廊，重新编号；使用 `FileManager.moveItem`；处理下载中与阅读中的冲突
4. 列表 UI：文件夹与画廊混排；点击文件夹进入下一级（复用同一列表）；编辑模式拖动排序；长按菜单「移动到分组…」；iPad 和 Mac 支持拖到文件夹行
5. 文件夹行视觉：与画廊行同高；封面区最多叠放 3 张封面（后两张缩小、错开、加阴影），角上显示数量；文字为「组名 · N 本 · M 本未完成 · 大小」，右侧箭头；淡色圆角底块。封面优先读本地第一页并降采样（约 150px，带缓存），没有再用 thumb URL
6. 下掉标签：删除 `DownloadsView` 中的标签选择栏、新建/重命名/删除标签、批量移动标签；删除 `DownloadManager.changeLabel` 和 `startDownload` 的 `label` 参数（调用方都未传）；数据库字段和表保留
