# EH-6 下载列表中的画廊，阅读时在线加载的页自动存入下载目录

目标：下载列表中的画廊（下载中、等待、暂停、失败），阅读时已在本地的页直接读本地，没有的页在线加载，加载成功后自动存进下载目录；下载器之后不再重复下载这些页
范围与不做项：涉及 `ReaderViewModel` 的本地目录判定和"阅读时同步下载"逻辑、`DownloadManager.saveWhileReading`、SpiderDen 写文件方式；不改「阅读时同步下载」设置对不在下载列表中的画廊的含义；不改下载器的派发顺序
事项类型与 TAPD 关键字：无 TAPD，本地编号 EH-6
相关文档：[EH-1 阅读器本地图片渲染慢](../阅读器本地图片渲染慢/TASK.md)（同一段读取逻辑）、[EH-3 下载失败率高](../下载失败率高/TASK.md)（下载器）、[EH-4 下载列表分组与排序](../下载列表分组与排序/TASK.md)（目录解析）；执行顺序与跨任务约束见 [本期执行计划](../PLAN.md)

## 行为与契约

允许变化：阅读器判定本地目录的时机；下载列表中画廊的在线页保存条件；图片文件写入方式（改为原子写入）
必须保持：不在下载列表中的画廊，仍由「阅读时同步下载」设置决定是否保存；同一页不会被保存两次；已有图片文件不被覆盖

| 输入或事件 | 预期结果 | 依据 |
| --- | --- | --- |
| 打开下载中的画廊，翻到已下载的页 | 读本地文件 | 现状已支持 |
| 翻到尚未下载的页 | 在线加载，成功后存入下载目录，下载列表进度 +1 | 修复方式第 2 项 |
| 下载器随后轮到这一页 | 发现文件已存在，跳过，不发请求 | 现状已支持（`SpiderQueen.swift:217`） |
| 刚加入下载、一张图都还没有时打开阅读 | 阅读过程中下载器写好的页也能读本地 | 修复方式第 1 项 |
| 下载器正在写某页时阅读器读到这页 | 读到的是完整文件，不会显示残图 | 修复方式第 3 项 |
| 开启「下载原图」时阅读下载中的画廊 | 阅读器加载的图不保存，由下载器下载原图 | 关键决策 1 |

现状（读代码得出，未经真机验证）：

- 本地还是在线是逐页判断的，不看整本的下载状态：`loadPage` 先找本地文件，没有再走网络（`ehviewer apple/ReaderViewModel.swift:917-927`）
- 但"这本有没有本地目录"只在打开阅读器时判断一次（同文件 :544-552），而且要求目录里至少已有一张图。刚加入下载、还没下完第一页就打开阅读的话，这次阅读全程都走网络，下载器之后写好的页也不会读
- 已有「阅读时同步下载」功能（设置页，默认关闭），但有一个条件把这个场景排除了：`guard !isDownloaded`（同文件 :819）。注释写的是"本地已有整本"，实际含义是"本地至少有一张"，所以下载列表中下载到一半的画廊，在线加载的页反而不会保存
- 该功能还要求详情页缓存里有画廊信息（同文件 :821），从下载页直接打开阅读时可能没有
- 下载器每页开始前会检查文件是否已存在（`Packages/EhSpider/Sources/EhSpider/SpiderQueen.swift:217`），所以阅读器先存好的页会被跳过；但两边同时在下同一页时仍会重复请求
- 图片写入是非原子的（`Packages/EhSpider/Sources/EhSpider/SpiderDen.swift:223`、`:330`、`:476`，以及 `DownloadManager.saveWhileReading`），另一方可能读到写了一半的文件

修复方式（计划）：

1. 本地目录判定：只要画廊在下载列表中就启用本地目录（不再要求已有图片），每页加载时检查文件是否存在
2. 自动保存：下载列表中的画廊，在线加载成功的页一律存入下载目录，不受「阅读时同步下载」设置影响；画廊信息改从 DownloadManager 的任务中取，不依赖详情页缓存；不在下载列表中的画廊保持原有设置逻辑
3. 原子写入：所有图片写入改为先写临时文件再改名（`Data.write(options: .atomic)`）
4. 避免同页重复下载：不做（关键决策 2）
