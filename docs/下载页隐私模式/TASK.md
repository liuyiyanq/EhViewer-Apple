# EH-9 下载页隐私模式

目标：在办公场所下载时，下载页不显示封面和标题，只看进度、速度和队列；页面停留期间屏幕不自动锁定，下载保持在前台进行
范围与不做项：只涉及 `ehviewer apple/DownloadsView.swift`。不改锁屏、实时活动、灵动岛、通知；不做多任务切换截图模糊；不改下载逻辑
事项类型与 TAPD 关键字：无 TAPD，本地编号 EH-9
相关文档：[EH-7 下载页网格视图](../下载页网格视图/TASK.md)（显示方式的保存与切换）；执行顺序见 [本期执行计划](../PLAN.md)

## 行为与契约

允许变化：下载页显示方式增加「隐私」；网格/列表切换从省略号菜单移到工具栏单独按钮
必须保持：列表、网格两种视图的行为不变（EH-7）；下载、排队、暂停逻辑不变；显示方式继续用 `downloadsLayoutMode` 保存

| 输入或事件 | 预期结果 | 依据 |
| --- | --- | --- |
| 工具栏「显示方式」按钮选「隐私」 | 下载页改为隐私视图，回到下载根目录；重启后仍是隐私视图 | 决策 1 |
| 设置「启动页」选「下载」并处于隐私模式 | 打开 App 直接进入隐私视图，不经过首页和其他视图 | 现有设置，决策 2 |
| 隐私视图顶部 | 显示队列总进度（页数和百分比）、队列中本数，右侧显示本机下载 ↓ 与上传 ↑ 速度（含其他 App 流量）；已完成数沿用原有的存储概览栏 | 决策 3、6 |
| 隐私视图列表 | 只列未完成的画廊，按状态分段：下载中、等待中（按队列顺序）、已暂停、失败，段头带本数，空的状态不显示；每项显示「#序号」（跨段连续）、进度条、页数，下载中显示速度；无封面、无标题、无分组名 | 决策 5 |
| 点某项的暂停或继续按钮 | 暂停或继续该画廊 | 决策 4 |
| 点某项其他位置、长按 | 无反应，不打开阅读器、详情或菜单 | 决策 4 |
| 停留在隐私视图 | 屏幕不自动锁定；离开下载页或切回列表、网格后恢复自动锁定 | 用户 11-12 决定 |
| 隐私视图下的工具栏 | 无搜索框；省略号菜单只保留全部开始、全部暂停、清空已完成 | 决策 4 |
